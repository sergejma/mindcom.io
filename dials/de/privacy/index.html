Datenschutz

Dials · Stand: 31. Oktober 2026

Dials zeigt deine WHOOP-Daten auf deiner Apple Watch.

Deine Daten

Deine Daten gehen direkt von WHOOP auf deine Geräte.

Anmeldung

Die Anmeldung bei WHOOP läuft über einen kleinen Server. Er fügt der Anmeldeanfrage nur den WHOOP-Schlüssel der App hinzu und speichert nichts: keine Tokens, keine Gesundheitsdaten, keine Logs mit personenbezogenen Daten.

Auf deinen Geräten

Die App behält nur die jeweils neuesten Werte, keinen Verlauf. iOS und watchOS speichern sie verschlüsselt. Wenn du die Verbindung trennst oder die App löschst, werden sie gelöscht.

Kein Tracking

Kein Tracking, keine Nutzungsanalyse, keine Werbung, keine Weitergabe an Dritte.

WHOOP

Für dein WHOOP-Konto gilt die Datenschutzerklärung von WHOOP. Dials ist eine unabhängige App und steht in keiner Verbindung zu WHOOP. Dials nutzt die WHOOP API.

Diese Website

Diese Website liegt bei GitHub Pages (GitHub, Inc., USA). Wenn du eine Seite öffnest, verarbeitet GitHub technische Daten wie deine IP-Adresse, um die Seite auszuliefern und den Dienst zu schützen. Mehr dazu in der Datenschutzerklärung von GitHub. Die Website setzt keine Cookies, nutzt keine Analyse und lädt nichts von anderen Servern.
